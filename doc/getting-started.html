Chapter 2. Getting Started

Your First Library

When you start KAthenaeum for the first time it has no libraries. Choose Library Manager in the sidebar, then the Catalog tab. The catalog lists every library Kiwix publishes; it starts on Wikipedia libraries. Each comes in up to three versions:

  • Introductions only (“mini”): the first part of each article. Small, and enough for many questions.

  • Full text, no pictures (“nopic”).

  • Full, with pictures (“maxi”): the largest. The whole English Wikipedia is about 120 GB.

Start with a small topic library (Chemistry, Astronomy, a person) to try KAthenaeum out, then download a larger one. Press Download; the Downloads tab shows its progress. When it finishes, KAthenaeum checks that the file is complete and undamaged, and the library appears under Libraries.

A ZIM file you already have can be added with Add File… in the Library Manager; it stays where it is.
