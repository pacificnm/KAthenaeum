Library Updates

Kiwix publishes new versions of its libraries every few months. Check for Updates in the Library Manager (or Check Now in Settings → Library Updates) looks in the catalog and says which of your libraries have a newer version. KAthenaeum also checks once a week by itself, and tells you only when it finds one; you can turn this off in Settings.

An update shows as Update to … on the library's card and in the Library Manager. It downloads the new version beside the old one; once it is ready, remove the old one.
