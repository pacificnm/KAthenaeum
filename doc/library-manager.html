Chapter 8. The Library Manager

Installed Libraries

The Installed tab lists your libraries. Click one for its details. The bin button removes a library from KAthenaeum, and its file too if you choose; chats, notes and projects keep their text, and they find the library again if you add it back.

New libraries go to the folder shown at the top of the tab; Change… picks another (files already downloaded stay where they are). Rescan Folder, in the menu, picks up ZIM files copied into it.
