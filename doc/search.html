Chapter 4. Searching

Type in the search box at the top of the sidebar and press Enter (or press CtrlF to get there). The Search page lists articles from every library: first those whose titles match, then those whose text does, each with the passage that matches. The menu beside the search box limits the search to one library.

Search finds words, not meanings: “why is the sky blue” finds articles containing those words. To have the question answered, ask it instead.

A library's home page has its own box, which finds articles by title as you type.

Note

Some libraries have no full-text index; they can be searched by title only. The Library Manager says so beside them.
