Chapter 9. Settings

Models

Whether Ollama is running, its address (normally http://localhost:11434), and the models for answers and for finding passages. If a model is missing, the command to install it is shown. If Ollama keeps only one model loaded, so that every question waits while it swaps them, Settings says so and how to change it.

Library Updates

The weekly check for newer versions of your libraries, and Check Now.

Reading

Articles across the whole window, or in a column of comfortable reading width.

Maps

The regions you have, adding more, and the folder they are kept in.

Storage

The folder for downloaded libraries, and where KAthenaeum keeps its database of chats, projects and settings.
