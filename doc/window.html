The Main Window

The sidebar on the left holds a search box and the places of the application, grouped as Read (Libraries, Search, Map) and Research (Ask, Chats, Projects), with the Library Manager, Settings, this handbook and About at the bottom. The place you are in is highlighted; a number beside Library Manager counts downloads in progress or library updates available.

The header shows the title of the page and, when you have gone deeper (a library, then an article), a back arrow. On a narrow window the sidebar is hidden; the button at the left of the header opens it.
